Sweet Crush
 
Este es un juego tipo "match-3" hecho para el Desafío I de Informática II. El tablero no se guarda como una tabla normal: vive comprimido en memoria, usando solo 3 bits por cada ficha, todo se hizo a mano, con punteros y memoria reservada manualmente.
Cada ficha ocupa exactamente 3 bits, uno pegado al otro sin ningún espacio de por medio, así que muchas veces una ficha queda repartida entre dos partes de la memoria, esto se resuelve leyendo y escribiendo bit por bit. La memoria siempre se reserva del tamaño justo que hace falta: al agregar una fila o columna se pide memoria nueva del tamaño exacto, y al eliminar, la memoria no se reduce de inmediato, solo cuando ya se está desperdiciando bastante espacio.
Para compilarlo hay que abrirlo en Qt Creator como un proyecto de consola normal .
Al arrancar el programa pide cuántas filas y columnas quiere el tablero, y después aparece un menú donde se puede: eliminar una ficha, agregar o quitar una fila en la posición que uno quiera, y lo mismo con las columnas. Después de cada jugada se muestra el tablero, cómo se ve por dentro en binario, y las estadísticas de la partida: cuántas eliminaciones se hicieron, cuántas combinaciones, cuántas cascadas y los puntos ganados.
El código está dividido en varios archivos, cada uno encargado de hacer distintas cosas: uno se encarga de reservar y liberar la memoria del tablero, otro de leer y escribir una ficha, otro de mostrar el tablero en pantalla, otro tiene todas las reglas del juego (combinaciones, gravedad, cascadas), otro lleva los contadores y la puntuación, y por último el archivo principal que junta todo en el menú del juego.
